# FITLOG — Train with Intent

FitLog is a high-performance, dark-gym-themed web application built with **Next.js App Router**, **TypeScript**, and **Tailwind CSS**. It allows fitness enthusiasts to browse an elite workout library, build a daily performance plan, save workouts for later, and manage their routine with instant state persistence.

---

## 🚀 Key Features

* **Dark Gym Aesthetic:** Built with a high-contrast dark theme, ambient glow radials.
* **Interactive Workout Library:** Explore 12 unique workouts complete with high-res Unsplash imagery, dynamic categories, difficulty ratings, and duration/calorie metrics.
* **Smart Performance Dashboard ("My Plan"):** 
  * Today's Plan management capped at 5 active exercises.
  * Dedicated Saved Lifts tab.
  * Real-time calculation of total active exercises, duration, and energy burn (calories).
  * Custom sorting by Duration (Shortest), Calories (Highest), and Rating (Top Rated).
* **State Persistence:** Seamlessly syncs user plan and saved lists using local storage.
* **Professional Typography & Layouts:** Smooth font smoothing with Google Inter, fully responsive layouts, and fluid scaling across all devices.
